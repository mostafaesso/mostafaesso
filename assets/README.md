# Assets

`profile-qr.png` — 600px, for digital use: slides, email signature, a screen.

`profile-qr-print.png` — 820px, for print: business cards, posters, a conference badge.

Both encode `https://github.com/mostafaesso` at error-correction level H, so roughly a
third of the code can be damaged or covered and it still scans. That headroom is what
lets a logo sit in the middle if you ever want one there.

**Print it at 2cm square or larger, on white.** Smaller than that and phone cameras
start failing at normal arm's length.
